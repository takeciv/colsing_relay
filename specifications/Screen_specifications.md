# 画面仕様

## 概要

画面一覧と各画面の仕様を定義する。

## 画面詳細仕様

### 共通

#### 1. 共通テーマ

 - 画面は中央寄せとする。
 - 全ての画面はPCとスマートフォンに対応する。

### SC001. ログイン画面

#### 1. 画面概要

 - ユーザーがログインを行う。
 - ユーザーはアドレスを入力することで、そのアドレス宛にログイン用のワンタイムパスワードが送られる。
 - アドレス入力後、ワンタイムパスワード送信ボタンを押すことでOTP画面に遷移する。

#### 2. 画面項目一覧

| 項目名 | 項目説明 |
|---|---|
| アドレス入力欄 | ログイン用のアドレスを入力するテキストボックス。|
| ワンタイムパスワード送信ボタン | ユーザーの入力したアドレスにワンタイムパスワードを送信し、OTP画面に遷移する。 |

#### 3. 画面構成

 - 画面上部に「ログイン画面」と表示されている。
 - 画面中央部にアドレス入力欄がある。
 - アドレス入力欄の下にワンタイムパスワード送信ボタンがある。

#### 4. 入力チェック仕様

 - アドレス入力欄にアドレスに使用不可の文字が入力された場合はエラーとする。
 - 「@」が1つじゃない場合はエラーとする。
 - アドレス入力欄が空白のままワンタイムパスワード送信ボタンが押された場合はエラーとする。

### SC002. OTP画面

#### 1. 画面概要

 - ユーザーがワンタイムパスワードの入力を行う。
 - ワンタイムパスワードを入力し、ログインボタンを押すことでログイン状態となる。
 - 初めてのログインの場合は初期情報入力画面に遷移する。それ以外の場合は遷移元画面に遷移する。

#### 2. 画面項目一覧

| 項目名 | 項目説明 |
|---|---|
| ワンタイムパスワード入力欄 | ワンタイムパスワードを入力するテキストボックス。英数字のみを許容する。 |
| ログインボタン | ワンタイムパスワードを検証し、ユーザーをログイン状態とする。 |

#### 3. 画面構成

 - 画面上部に「ワンタイムパスワード入力」と表示されている。
 - 画面中央部にワンタイムパスワード入力欄がある。
 - ワンタイムパスワード入力欄の下にログインボタンがある。

#### 4. 入力チェック仕様

 - ワンタイムパスワード入力欄に使用不可文字が入力された場合はエラーとする。
 - ワンタイムパスワード入力欄が空白のままログインボタンが押された場合はエラーとする。
 - ワンタイムパスワードが誤っていた場合はエラーとする。

### SC003. 初期情報入力画面

#### 1. 画面概要

 - 初めてログインした場合、ユーザーは初期情報を入力する。

#### 2. 画面項目一覧

| 項目名 | 項目説明 |
|---|---|
| ニックネーム入力欄 | ニックネームを入力するテキストボックス。128文字以内。 |
| 登録ボタン | 入力した情報をDBに登録し、遷移元画面に遷移する。 |

#### 3. 画面構成

 - 画面上部に「ユーザー情報入力」と表示されている。
 - 「ニックネーム」ラベルがある。
 - ラベルの下にニックネーム入力欄がある。
 - ニックネーム入力欄の下に登録ボタンがある。

#### 4. 入力チェック仕様

 - ニックネーム入力欄が規定文字数より多い場合はエラーとする。
 - ニックネーム入力欄に空白のまま登録ボタンが押された場合はエラーとする。

### SC010. 検索画面

#### 1. 画面概要

 - ユーザーがイベントを検索する。
 - 検索した結果は同じ画面に表示される。

#### 2. 画面項目一覧

| 項目名 | 項目説明 |
|---|---|
| ログインボタン | ログイン画面に遷移するためのボタン。 |
| ポータルボタン | ポータル画面に遷移するためのボタン。 |
| 検索ワード入力欄 | 検索するためのキーワードを入力するテキストボックス。128文字以内。 |
| 検索ボタン | 検索を実行するボタン。 |
| 前ページ移動ボタン | イベントが複数ページの場合に表示。 |
| 後ページ移動ボタン | イベントが複数ページの場合に表示。 |
| ソート順選択ボタン | 検索実行後に表示。イベント開始日時、イベント名、イベント起案者が選択肢。デフォルトはイベント開始日時。 |
| イベント画像 | イベントごとに表示。イベントの画像。正方形。 |
| イベント名 | イベントごとに表示。イベントの名称。表示枠を超える場合は「...」にて省略される。 |
| イベント起案者 | イベントごとに表示。イベントを起案した人のニックネーム。表示枠を超える場合は「...」にて省略される。 |
| イベント概要 | イベントごとに表示。イベントの概要。表示枠を超える場合は「...」にて省略される。 |
| イベント開始日時 | イベントごとに表示。イベントの開始日時。「yyyy/mm/dd HH:MM」の形式で表示。 |
| イベント終了日時 | イベントごとに表示。イベントの終了日時。「yyyy/mm/dd HH:MM」の形式で表示。 |
| イベント詳細ボタン | イベントごとに表示。イベント詳細画面に遷移するためのボタン。 |

#### 3. 画面構成

 - 画面最上部にヘッダー部があり、その中にポータルボタンとログインボタンがある。
 - ログインしている時はポータルボタンが表示され、ログインしていない時はログインボタンが表示される。
 - 画面上部に「イベント検索」と表示されている。
 - 未検索時
  - 画面中央に検索ワード入力欄がある。
  - 検索ワード入力欄の下に検索ボタンがある。
 - 検索実行後
  - 画面上部に検索ワード入力欄がある。
  - 検索ワード入力欄の下に検索ボタンがある。
  - セクションを分ける線の下に検索結果が表示される。
  - 線の下に検索されたイベントの一覧が表示される。1ページに最大20件表示され、超える場合はページャーが設定される。
  - イベントの一覧は、左側にイベント画像、右側にイベント名、イベント起案者、イベント概要、イベント開始日時、イベント終了日時、下部にイベント詳細ボタンが表示される。

#### 4. 入力チェック仕様

 - 検索ワード入力欄が空白の場合もエラーにはしない。全件検索とする。

### SC030. イベント詳細画面

#### 1. 画面概要

 - イベントの詳細を表示する画面。
 - イベント走者の一覧を表示する。
 - この画面のみ1秒に1回イベント情報取得APIをコールし、リアルタイム情報を取得する。
 - この画面はスタイルをDBで管理し、背景色、文字色、タイトルの色などのスタイルをイベントごとに変更可能とする。

#### 2. 画面項目一覧

| 項目名 | 項目説明 |
|---|---|
| ポータルボタン | ポータル画面に遷移するためのボタン。 |
| フォローボタン | イベントをフォローするためのボタン。 |
| フォロー解除ボタン | イベントのフォローを解除するためのボタン。 |
| ログインボタン | ログイン画面に遷移するためのボタン。 |
| イベントバナー画像 | イベントのバナー画像。 |
| イベント名 | イベントの名称。 |
| イベント起案者 | イベントを起案した人のニックネーム。 |
| イベント概要 | イベントの概要。 |
| イベント開始日時 | イベント全体の開始日時。「yyyy/mm/dd HH:MM」の形式で表示。 |
| イベント終了日時 | イベント全体の終了日時。「yyyy/mm/dd HH:MM」の形式で表示。 |
| イベント走者画像 | イベント走者ごとに表示。イベント走者の画像。 |
| イベント走者名 | イベント走者ごとに表示。イベント走者の名前。 |
| イベント走者概要 | イベント走者ごとに表示。イベント走者の概要。 |
| イベント走者プロフィールリンク | イベント走者ごとに表示。イベント走者のプロフィールのリンク。 |
| イベント走者配信枠リンク | イベント走者ごとに表示。イベント走者の配信枠のリンク。 |
| イベント走者開始日時 | イベント走者ごとに表示。イベント走者の配信を開始する日時。「yyyy/mm/dd HH:MM」の形式で表示。 |
| イベント走者終了日時 | イベント走者ごとに表示。イベント走者の配信を終了する日時。「yyyy/mm/dd HH:MM」の形式で表示。 |
| イベント走者ステータス | イベント走者ごとに表示。イベント走者の配信枠のステータス。 |
| イベント走者ステータス更新ボタン | イベント走者ごとに表示。イベント走者ステータス更新ダイアログを表示する。 |

#### 3. 画面構成

 - 画面最上部にヘッダー部があり、その中にポータルボタン、フォローボタン、フォロー解除ボタン、ログインボタンがある。
 - フォローボタンとフォロー解除ボタンはイベント起票者は表示されない。フォローボタンとフォロー解除ボタンはログインしていない時は表示されない。
 - フォローボタンはフォローしていない時のみ表示される。フォロー解除ボタンはフォローしている時のみ表示される。
 - ログインしていない時のみログインボタンが表示される。
 - 画面上部にイベント名が表示される。
 - イベント名の下にイベント詳細情報として、イベント概要、イベント起案者、イベント開始日時、イベント終了日時が表示される。
 - イベント詳細情報の下に、イベント走者情報がイベント走者開始日時順に表示される。
 - イベント走者の情報は以下の構成とする。
  - 上部左側にイベント走者画像がある。
  - 上部右側に、イベント走者名、イベント走者ステータス、イベント走者開始日時、イベント走者終了日時、イベント走者プロフィールリンク、イベント走者配信枠リンクが縦に並ぶ。
  - 下部にイベント走者概要がある。
  - イベント走者プロフィールリンクはURLそのままでなく、「プロフィール」という文字。イベント走者配信枠リンクはURLそのままでなく、「配信リンク」という文字。
  - ユーザーがイベント起票者の場合のみ、イベント走者概要の下にイベント走者ステータス更新ボタンがある。

#### 4. 入力チェック仕様

 - なし。

 - ユーザーがイベント詳細を作成するための画面。

#### 2. 画面項目一覧

| イベント走者概要入力欄 | イベント走者ごとに表示。イベント走者の概要を入力するテキストボックス。 |
| イベント走者プロフィールリンク入力欄 | イベント走者ごとに表示。イベント走者のプロフィールのURLを入力するテキストボックス。 |
| イベント走者配信枠リンク入力欄 | イベント走者ごとに表示。イベント走者の配信枠のURLを入力するテキストボックス。 |
| イベント走者開始日時入力欄 | イベント走者ごとに表示。イベント走者の配信を開始する日時を入力するダイアログ。 |
| イベント走者終了日時入力欄 | イベント走者ごとに表示。イベント走者の配信を終了する日時を入力するダイアログ。 |

| イベント詳細情報プレビューボタン | イベント詳細情報をDBに登録し、イベント詳細情報プレビュー画面に遷移する。 |
| キャンセルボタン | 作成内容を破棄してポータル画面に遷移する。 |

#### 3. 画面構成

 - 画面上部に「イベント詳細作成画面」と表示される。
 - イベント名入力欄が表示される。
 - イベント名入力欄の下にイベント詳細情報入力欄として、イベント概要入力欄、イベント開始日時入力欄、イベント開始日時自動入力ボタン、イベント終了日時入力欄、イベント終了日時自動入力ボタンが表示される。
 - イベント詳細情報入力欄の下に、イベント走者追加ボタンが表示される。
 - イベント走者ごとに以下の情報がある。
  - イベント走者画像アップロードダイアログ、イベント走者名入力欄、イベント走者開始日時入力欄、イベント走者終了日時入力欄、イベント走者プロフィールリンク入力欄、イベント走者配信枠リンク入力欄、イベント走者概要入力欄が縦に並ぶ。
 - PC画面の場合は一番下にイベント詳細情報プレビューボタンがある。スマートフォン画面の場合は画面の下部に固定でイベント詳細情報プレビューボタンがある。

#### 4. 入力チェック仕様

 - イベント名入力欄が空白の場合はエラーとする。
 - イベント走者情報がある場合、イベント走者名入力欄が空白の場合はエラーとする。
 - イベントバナー画像、イベント走者画像は、PNG、JPGのみを許容し、それ以外はエラーとする。

### SC032. イベント詳細プレビュー画面

#### 1. 画面概要

 - イベント詳細作成画面にて作成した内容のプレビューを表示する。

#### 2. 画面項目一覧

### SC034. イベント走者ステータス更新ダイアログ

#### 1. 画面概要

 - イベント走者のステータスとイベント走者プロフィールリンクとイベント走者配信枠リンクを更新する。

#### 2. 画面項目一覧

| 項目名 | 項目説明 |
|---|---|
| イベント走者名 | イベント走者の名前。 |
| イベント走者ステータス入力ダイアログ | イベント走者のステータスを更新するダイアログ。開始前、実施中、終了、の3つがある。 |
| イベント走者プロフィールリンク入力欄 | イベント走者ごとに表示。イベント走者のプロフィールのURLを入力するテキストボックス。 |
| イベント走者配信枠リンク入力欄 | イベント走者ごとに表示。イベント走者の配信枠のURLを入力するテキストボックス。 |
| 更新ボタン | 更新した情報をDBに登録し、ダイアログを閉じ、通知を飛ばす。 |
| キャンセルボタン | 更新した内容を破棄し、ダイアログを閉じる。 |

#### 3. 画面構成

 - イベント詳細画面にかぶさってダイアログとして表示される。
 - ダイアログ上部に「イベント走者ステータス更新」の文字がある。
 - イベント走者ステータス入力ダイアログ、イベント走者プロフィールリンク入力欄、イベント走者配信枠リンク入力欄が縦に並ぶ。
 - ダイアログの一番下に更新ボタンとキャンセルボタンがある。

#### 4. 入力チェック仕様

 - なし。
