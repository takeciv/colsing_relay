# URL仕様

## 概要

URL仕様を定義する。

## 仕様

| 画面 | URL |
|---|---|
| ログイン画面 | /login |
| OTP画面 | /otp |
| 初期情報入力画面 | /init |
| ユーザー情報更新画面 | /user |
| 検索画面 | /index |
| ポータル画面 | /portal |
| イベント詳細画面 | /event?id=xxxx |
| イベント詳細作成画面 | /create |
| イベント詳細プレビュー画面 | /preview?id=xxxx |
| イベント詳細更新画面 | /edit?id=xxxx |
